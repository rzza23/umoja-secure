## Developer Certificate of Origin (DCO)

All contributions must be signed off under the Developer Certificate of
Origin, version 1.1:

    https://developercertificate.org/

By adding a `Signed-off-by` line to your commits, you certify that you have
the right to submit the contribution under the project's license.

To add the sign-off automatically, use:

    git commit -s

The resulting commit message will include a line like:

    Signed-off-by: Jane Developer <jane@example.com>

## Why the DCO

The DCO confirms that every contributor has the right to license their work
under AGPLv3, and it preserves the project's ability to offer a commercial
license (dual licensing) to customers who cannot comply with AGPLv3 terms.
Without a DCO, that option is not available.

## Pull requests

- One task per pull request. Reference the task ID in the title.
- Follow the workflow in `UMOJA-SECURE-BUILD-MASTER.md` §7.
- All tests must pass. Do not disable tests to make them pass.
- Do not add a dependency without justification in the PR description.

## Security issues

Do not file security issues publicly. Contact the maintainer directly.
